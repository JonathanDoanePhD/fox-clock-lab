# Fox Clock Lab

[Open Fox Clock Lab](https://jonathandoanephd.github.io/fox-clock-lab/)

Explore modular arithmetic on a clock. On a 5-clock, 7, 2, and −3 all land at the same hour. Drag the hand to see how numbers wrap around, then use the clock to solve a problem.

## How to use it

1. Choose a clock size from 1 to 12. Toggle the inner labels for zero and negative numbers and the outer labels for the next lap.
2. Drag the hand to an hour mark. You can also focus the hand and move it with the arrow keys.
3. Try addition or subtraction, or turn on **Multiplication**. Turn on **Missing number** to move the blank inside the equation.
4. In **Regular answer**, enter any integer that lands at the right hour. An equivalent answer outside the modular range pulses yellow and green. In **Modular answer**, use the representative from zero to one less than the clock size.
5. Optionally enter initials before a turn. **Export Excel** downloads all attempts in order, plus tabs for each set of initials and for uninitialed attempts.

Attempts stay in the browser where they were entered. Fox Clock Lab uses HTML, CSS, and JavaScript and has no build step. To run it locally, open `index.html` in a modern browser.
